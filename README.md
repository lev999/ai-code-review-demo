# AI code review demo

This repository starts with a small test of the pull request policy for a two-list task board. The project will grow here. The example uses original data.

Run the checks with `python3 -m unittest discover -s tests -v`. The policy uses a trusted copy of the required-test list. A routine example can merge automatically. A change to a business rule waits for a reviewer decision. In this demonstration the user role is simulated and is identified as such. GitHub runs the checks and enforces the merge requirements.
